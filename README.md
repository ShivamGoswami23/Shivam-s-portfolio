# ⚡ Shan — Creative Developer Portfolio

[![Portfolio Banner](images/shan-main-portrait.jpg?v=3)](http://localhost:3000/)

A modern, high-performance, award-grade editorial developer portfolio built with HTML5, Vanilla CSS3, JavaScript (ES6+), **GSAP 3**, and **Locomotive Scroll 4**. Designed with minimalist luxury aesthetics, interactive tilt elements, full-screen lightbox modal viewers, and 60fps smooth scroll animations.

## 🌟 Key Features & Architecture

- **🎨 Modern Luxury Design System**: Custom typography pairing using *Fjalla One* and *Gilroy*, featuring high-contrast black & white tones, glassmorphism elements, and an Angular Geometric 'S' monogram logo.
- **⚡ Smooth Locomotive & GSAP Motion**: Integrated Locomotive Scroll v4 with GSAP ScrollTrigger for parallax scrolling, mask text reveals, and dynamic mouse-follower cursor spotlight.
- **📱 100% Multi-Device Responsiveness**: Tailored layout adaptation with fluid typography across Mobile, Tablet, Laptop, and Desktop screens.
- **👤 Editorial Bio Section**: Features a floating location badge (`📍 Bangalore, India`), full-stack expertise cards, developer philosophy quote box, and stacked mobile action buttons (`MY CV` & `LET'S TALK`).
- **🛠️ Black & White Tech Skills Bento Matrix**: 5-domain categorization featuring interactive technology pill badges:
  - **(01) Frontend Architecture**: React, Next.js, TypeScript, Tailwind CSS, GSAP, Framer Motion
  - **(02) Backend Engineering**: Node.js, Express.js, Java, REST APIs
  - **(03) Database Systems**: PostgreSQL, MongoDB, Supabase, Firebase
  - **(04) Testing & QA**: Manual Testing, API Testing, Regression Testing, Postman, SDLC / STLC
  - **(05) DevOps & Tools**: Git, GitHub, Docker, Vercel, Linux
- **🖼️ Full-Screen Lightbox Modal**: View high-resolution certificates (e.g., MERN Stack Developer from *Be Practical Tech Solutions, Bangalore*) with dark blur backdrop and `Escape` key controls.
- **📩 Interactive Contact Form**: Built-in client-side form submission handler with inline `#submit-success` confirmation card.

## 💻 Local Setup & Development Guide

Follow these simple steps to run the portfolio locally on your computer:

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/shajith23/portfolio-design.git
   cd portfolio-design
   ```

2. **Launch Development Server**:
   Using Python 3:
   ```bash
   python3 -m http.server 3000
   ```
   Or using Node.js `npx`:
   ```bash
   npx serve .
   ```

3. **View Live Project**:
   Open your browser and navigate to `http://localhost:3000/`.
